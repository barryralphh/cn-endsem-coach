# HDLC (High-level Data Link Control)

## 10 Golden Points
1. HDLC is a bit-oriented data link layer protocol for point to point and multipoint links
2. Frame format: Flag, Address, Control, Information, FCS, Flag
3. Flag is 01111110 and it marks start and end of every frame
4. Address is 8 bits, control is 8 bits, FCS is 16 bit CRC
5. Bit stuffing: after five consecutive ones the sender inserts one zero
6. Receiver destuffing: after five consecutive ones remove the next zero
7. Three frame types: I frame for data, S frame for flow and error control, U frame for link management
8. First bit of control: 0 means I frame, 10 means S frame, 11 means U frame
9. I frame control = 0, N of S 3 bits, P slash F bit, N of R 3 bits. Window size can be 7
10. Modes: NRM normal response mode, ABM asynchronous balanced mode. Stations: primary, secondary, combined

## Worked calculations

### Scene 1: HDLC = train. FLAG 01111110 = start / end ka jhanda
    ## Flag in hex
    0111 1110
    0111 = 7
    1110 = E
    ! Flag = 7E (hex)
    ~ 0x7E appears in PPP too
    ## Fields
    Address: 8 bits (secondary id)
    Control: 8 bits (frame type)
    FCS: 16 bit CRC

### Scene 2: Bit stuffing: 5 ones ke baad ek 0 daalo
    ## Q: stuff 011111101111110
    Bits: 0 | 111111 | 0 | 111111 | 0
    run 1: five 1s -> add 0, then 1
    run 2: five 1s -> add 0, then 1
    Stuffed:
    0 111110 1 0 111110 1 0
    ! 01111101011111010
    Length: 15 + 2 = 17 bits

### Scene 3: Destuff: 5 ones ke baad wala 0 hata do
    ## Destuff 01111101011111010
    0 11111 [0] 1 0 11111 [0] 1 0
    remove bracketed 0s
    ! 011111101111110
    Matches original (15 bits)
    ~ Rule: 11111 then 0 = remove

### Scene 4: Control field: pehle bit(s) se frame type pata chalta hai
    ## Decode control = 5B (hex)
    5 = 0101, B = 1011
    5B = 0101 1011
    first bit = 0 -> I-frame
    N(S) = 101 = 5
    P/F = 1
    N(R) = 011 = 3
    ! I-frame, N(S)=5, N(R)=3, P/F=1

### Scene 5: 5 marks: Frame diagram + Bit stuffing + I/S/U + Modes
    ## Sequence number
    3 bits -> 2^3 = 8 numbers
    0 to 7
    Max window = 8 - 1 = 7
    ! Window size = 7
    ~ Go-Back-N style rule
