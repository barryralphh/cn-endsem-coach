# IPv4 Header and Fragmentation

## 10 Golden Points
1. IPv4 header is minimum 20 bytes and maximum 60 bytes
2. HLEN field counts in 4 byte words, so header length = HLEN x 4
3. Total length field is 16 bits, so maximum datagram is 65535 bytes
4. MTU is the biggest data a link can carry, Ethernet MTU is 1500 bytes
5. Each fragment header is 20 bytes, so data per fragment = MTU minus 20
6. Data per fragment must be a multiple of 8 because offset is in units of 8 bytes
7. Fragment offset = starting byte of data divided by 8
8. MF flag is 1 for all fragments except the last one, DF flag 1 means do not fragment
9. Fragments are reassembled only at the destination, using Identification, offset and MF
10. Protocol field: 1 is ICMP, 6 is TCP, 17 is UDP. TTL decreases by one at every router

## Worked calculations

### Scene 1: Bada saaman, chhota truck: tukde karo, label lagao (fragmentation)
    ## Header size
    HLEN = 5 -> 5 x 4 = 20 bytes (min)
    HLEN = 15 -> 15 x 4 = 60 bytes (max)
    Total length 16 bits
    2^16 - 1 = 65535 bytes
    ! Header: 20 to 60 bytes
    ~ Protocol: 1 ICMP, 6 TCP, 17 UDP

### Scene 2: Data per fragment = MTU - 20, aur 8 ka multiple hona chahiye
    ## Step 1: data
    4000 - 20 = 3980 bytes
    ## Step 2: max data / fragment
    1500 - 20 = 1480
    1480 / 8 = 185  (whole number OK)
    ! 1480 B data per fragment
    ## Step 3: number of fragments
    3980 / 1480 = 2.69 -> 3 fragments

### Scene 3: Last fragment: MF = 0. Baaki sab ka MF = 1
    ## Offsets
    F1: 0 / 8 = 0
    F2: 1480 / 8 = 185
    F3: 2960 / 8 = 370
    ## Last fragment
    data = 3980 - 1480 - 1480
         = 1020 bytes
    total length = 1020 + 20 = 1040
    ! F3: len 1040, off 370, MF 0

### Scene 4: Re-fragmentation: pehle 8 ka multiple, last piece ka MF = original MF
    ## Step 1
    576 - 20 = 556
    556 / 8 = 69.5 -> not whole
    use 69 x 8 = 552
    ## Step 2: pieces
    1480 = 552 + 552 + 376
    ## Step 3: offsets
    P1: 185
    P2: 185 + 552/8 = 185 + 69 = 254
    P3: 254 + 69 = 323
    ! P3 keeps MF = 1

### Scene 5: Hex header: 45 = version 4, HLEN 5. Reassembly sirf destination par
    ## Decode 45 00 00 3C
    4 -> version 4
    5 -> HLEN = 5 x 4 = 20 bytes
    003C = 3x16 + 12 = 60
    ! Total length = 60 bytes
    ## Flags 4000 (hex)
    4000 = 0100 0000 0000 0000
    flags = 010 -> DF = 1, MF = 0
    offset = 0
    ! Do-not-fragment, first and only
