# IP Addresses, Special Addresses, IPv6

## 10 Golden Points
1. IPv4 address is 32 bits written as four decimal numbers called dotted decimal
2. Class A starts with bit 0, range 1 to 126. Class B starts with 10, range 128 to 191
3. Class C starts with 110, range 192 to 223. Class D starts with 1110, 224 to 239, multicast
4. Class E is 240 to 255, reserved. Default masks: A is slash 8, B is slash 16, C is slash 24
5. Network address means host part is all zeros, broadcast address means host part is all ones
6. All zeros 0.0.0.0 means this host, used as source at boot time
7. All ones 255.255.255.255 is limited broadcast, never forwarded by a router
8. Loopback is 127.x.x.x, usually 127.0.0.1, used for testing your own machine
9. Private ranges: 10.0.0.0 slash 8, 172.16 to 172.31, and 192.168.0.0 slash 16
10. IPv6 is 128 bits, 8 groups of 4 hex digits, drop leading zeros and use double colon once

## Worked calculations

### Scene 1: IP = ghar ka pata. NetID = colony, HostID = flat number
    ## Find the class
    Look at FIRST octet
    194 -> in 192..223
    ! 194.x.x.x = Class C
    ## Binary check
    194 = 1100 0010
    starts with 110 -> Class C
    ~ 127 is loopback, not class A

### Scene 2: Hex -> dotted: har 2 hex digits = 1 octet
    ## Q: C22F1582 -> dotted
    C2 = 12x16 + 2 = 194
    2F = 2x16 + 15 = 47
    15 = 1x16 + 5 = 21
    82 = 8x16 + 2 = 130
    ! 194.47.21.130
    ## Net / host / broadcast
    Class C -> NetID 194.47.21
    ! Network addr: 194.47.21.0
    ! HostID: 130
    ! Broadcast: 194.47.21.255

### Scene 3: Dotted -> hex: octet / 16 = pehla digit, remainder = doosra
    ## Q: 192.168.10.5 -> hex
    192 / 16 = 12 rem 0 -> C0
    168 / 16 = 10 rem 8 -> A8
    10 / 16 = 0 rem 10 -> 0A
    5 -> 05
    ! C0A80A05
    ## Binary
    11000000.10101000.00001010.00000101

### Scene 4: Special: 0.0.0.0 | 255.255.255.255 | 127.x.x.x | Private ranges
    ## Private ranges
    10.0.0.0 - 10.255.255.255
    172.16.0.0 - 172.31.255.255
    192.168.0.0 - 192.168.255.255
    ! 3 private blocks
    ## Count 10/8
    2^24 = 16,777,216 addresses
    ~ 172.16/12 -> 2^20 = 1,048,576
    ~ 192.168/16 -> 2^16 = 65,536
