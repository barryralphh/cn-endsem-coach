# Subnetting (Fixed Length)

## 10 Golden Points
1. Subnetting divides one network into smaller networks by borrowing host bits
2. If you borrow n bits you get 2 to the power n subnets
3. Hosts per subnet = 2 to the power h minus 2, where h is the remaining host bits
4. Subnet mask has ones for network and subnet bits and zeros for host bits
5. Block size = 256 minus the interesting mask octet, or 2 to the power h
6. Network address is the first address of a block, broadcast address is the last
7. Usable hosts are between network address plus 1 and broadcast address minus 1
8. Slash 24 to 32 subnets needs n = 5 so new prefix is slash 29 and mask 255.255.255.248
9. To find the subnet of an IP, do bitwise AND of the IP with the mask
10. Mask 255.255.240.0 is slash 20 because 8 + 8 + 4 = 20, giving 4094 hosts

## Worked calculations

### Scene 1: Subnet = colony ki galiyan. n bits udhaar = 2^n subnets
    ## Formulas
    Subnets = 2^n
    Hosts = 2^h - 2
    Block size = 2^h
    ~ -2 = network + broadcast
    ## Quick check
    n = 3 -> h = 5
    hosts = 2^5 - 2 = 30
    ! 8 subnets, 30 hosts each

### Scene 2: 32 subnets -> n = 5 -> /29 -> 255.255.255.248
    ## Find the mask
    32 = 2^5 -> n = 5
    prefix = 24 + 5 = 29
    last octet: 11111000
    128+64+32+16+8 = 248
    ! Mask = 255.255.255.248 (/29)
    ## Block and hosts
    h = 8 - 5 = 3
    block = 2^3 = 8
    hosts = 8 - 2 = 6

### Scene 3: Last subnet start = (32 - 1) x 8 = 248
    ## Subnet 32
    index = 32 - 1 = 31
    start = 31 x 8 = 248
    end = 248 + 8 - 1 = 255
    ! First: 211.17.180.248/29
    ! Last : 211.17.180.255/29
    ~ Usable hosts: .249 to .254

### Scene 4: Block size nikalo, phir dekho IP kis block mein hai
    ## Step 1: mask
    /26 -> 255.255.255.192
    ## Step 2: block
    256 - 192 = 64
    ## Step 3: find block of 130
    128 <= 130 <= 191
    ! Network  : 172.16.35.128
    ! Broadcast: 172.16.35.191
    ! Usable   : .129 to .190
    Hosts = 2^6 - 2 = 62

### Scene 5: Mask to prefix: ones ginte jao. Same subnet: AND karo
    ## Q: 255.255.240.0 -> prefix
    8 + 8 + 4 + 0 = 20
    host bits = 32 - 20 = 12
    ! /20, hosts = 2^12 - 2 = 4094
    ## Q: same subnet? /27
    192.168.1.40 and 192.168.1.60
    block = 256 - 224 = 32
    40 and 60 are both in 32 - 63
    ! YES, same subnet
