# VLSM and CIDR Block Allocation

## 10 Golden Points
1. CIDR notation is address slash prefix, for example 190.100.0.0 slash 16
2. Block size is always a power of 2, so round every requirement up to the next power of 2
3. Prefix = 32 minus log base 2 of block size. 256 is slash 24, 128 is slash 25, 64 is slash 26, 16 is slash 28
4. Always allocate the biggest block first, then the smaller ones
5. A block must start at an address that is a multiple of its own size
6. Group total = number of customers x addresses per customer
7. Remaining addresses = total block minus the sum of all allocated blocks
8. Slash 16 has 65536 addresses, slash 24 has 256, slash 25 has 128, slash 26 has 64
9. Supernetting joins contiguous blocks: 4 class C blocks become slash 22 with mask 255.255.252.0
10. Blocks to be aggregated must be a power of 2 in count and the first one must be aligned

## Worked calculations

### Scene 1: Zameen baantna: bade grahak pehle, size = power of 2
    ## Prefix from size
    256 = 2^8 -> 32 - 8 = /24
    128 = 2^7 -> 32 - 7 = /25
    64 = 2^6 -> 32 - 6 = /26
    16 = 2^4 -> 32 - 4 = /28
    ! prefix = 32 - log2(size)

### Scene 2: Group total = customers x addresses per customer
    ## Group totals
    G1: 64 x 256 = 16,384 = 2^14 -> /18
    G2: 128 x 128 = 16,384 = 2^14 -> /18
    G3: 128 x 64 = 8,192 = 2^13 -> /19
    ## Used and remaining
    16384 + 16384 + 8192 = 40,960
    65,536 - 40,960 = 24,576
    ! Remaining = 24,576 addresses

### Scene 3: Ek group khatam, doosra wahi se shuru
    ## Check the ranges
    G1: 16384 / 256 = 64 -> 3rd octet 0..63
    G2: starts at 64 -> 64..127
    G3: 8192 / 256 = 32 -> 128..159
    Free: 160..255 = 96 blocks
    96 x 256 = 24,576
    ! matches 24,576
    ~ last cust G3: 190.100.159.192/26

### Scene 4: Round up -> bade se chhota -> start address = multiple of size
    ## Round and allocate
    120 -> 128 (/25) start .0
    60 -> 64 (/26) start .128
    10 -> 16 (/28) start .192
    ## Remaining
    used = 128 + 64 + 16 = 208
    256 - 208 = 48
    ! 48 free: 14.24.74.208 to .255
    ~ 192 is a multiple of 16: OK

### Scene 5: Supernet: common bits ginti karo -> naya prefix
    ## Aggregate 4 x /24
    common bits = 16 + 6 = 22
    mask 3rd octet = 1111 1100 = 252
    ! 200.1.0.0/22
    ! Mask 255.255.252.0
    addresses = 4 x 256 = 1024 = 2^10
