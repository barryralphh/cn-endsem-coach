# ARP, RARP and NAT

## 10 Golden Points
1. ARP maps an IP address to a MAC address, RARP maps a MAC address to an IP address
2. ARP request is broadcast to FF:FF:FF:FF:FF:FF, ARP reply is unicast
3. ARP packet fields: hardware type, protocol type, HLEN 6, PLEN 4, operation, sender MAC, sender IP, target MAC, target IP
4. ARP operation code: 1 request, 2 reply. RARP: 3 request, 4 reply
5. In an ARP request the target MAC field is all zeros because it is unknown
6. ARP packet is 28 bytes, padded to 46 bytes to fit the Ethernet minimum payload
7. Ethernet type field: 0806 hex for ARP, 0800 hex for IP
8. RARP was used by diskless machines at boot and is replaced by BOOTP and DHCP
9. NAT replaces private source IP with a public IP, and keeps a translation table
10. PAT or NAT overload uses port numbers so many private hosts share one public IP

### Scene 1: ARP = class mein chillao: Rahul ki seat kaunsi? Sirf Rahul bolega
    ## ARP operation codes
    Request = 1
    Reply   = 2
    ## Ethernet type field
    ARP = 0806 (hex)
    IP  = 0800 (hex)
    0806 = 8x256 + 6 = 2054
    ! ARP frame type = 0x0806
    ~ Cache entry expires after minutes

### Scene 2: ARP packet = 28 bytes. Ethernet padding = 18 bytes
    ## Packet size
    2 + 2 + 1 + 1 + 2 = 8
    6 + 4 + 6 + 4 = 20
    ! ARP packet = 28 bytes
    ## Ethernet minimum payload
    46 - 28 = 18 bytes padding
    ! Frame = 14 + 46 + 4 = 64 B

### Scene 3: RARP = MAC se IP pooch na. Ab DHCP ne replace kar diya
    ## RARP flow
    1. Booting host broadcasts its MAC
    2. RARP server looks up table
    3. Server replies with the IP
    ! Gives ONLY the IP
    ~ No mask, no gateway, no DNS
    ~ Replaced by BOOTP -> DHCP

### Scene 4: NAT = receptionist: andar ke naam ko bahar ka naam deta hai
    ## One packet out and back
    OUT: src 192.168.1.10:5000
         -> src 203.0.113.5:61000
    reply dst 203.0.113.5:61000
    table lookup:
         -> dst 192.168.1.10:5000
    ! Table maps (IP, port) pairs
    ~ Saves IPv4 addresses, hides LAN
