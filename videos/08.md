# ICMP and IGMP

## 10 Golden Points
1. ICMP reports errors and gives query messages, it does not correct errors
2. ICMP is carried inside an IP datagram, protocol number 1
3. Error messages: destination unreachable type 3, time exceeded type 11, parameter problem 12, redirect 5
4. Query messages: echo request type 8 and echo reply type 0, used by ping
5. ICMP error includes the IP header plus first 8 bytes of the original datagram data
6. Those 8 bytes contain the port numbers so the sender knows which process caused the error
7. No ICMP error is generated for another ICMP error message
8. Traceroute works by sending packets with TTL 1, 2, 3 and reading the time exceeded replies
9. Checksum: add all 16 bit words, wrap the carry around, take ones complement
10. IGMP lets hosts tell the local router which multicast groups they belong to, all hosts group is 224.0.0.1

## Worked calculations

### Scene 1: ICMP = post office ki parchi: address nahi mila!
    ## ICMP inside IP
    IP protocol field = 1
    ! ICMP -> protocol 1
    ## Ping
    sends type 8
    gets back type 0
    ~ ping = echo request + reply
    ## Traceroute
    TTL = 1, 2, 3 ...
    routers reply type 11
    ! maps the path hop by hop

### Scene 2: IP header + 8 bytes = kaun sa datagram + kaun sa process (ports)
    ## Sizes
    UDP header = 8 bytes (full)
    TCP first 8 B = src port, dst port, seq number
    ! 8 B always has the ports
    ## Rule
    no ICMP error for an ICMP error
    no error for multicast / broadcast
    ~ avoids error storms

### Scene 3: Checksum = words jodo + carry wapas jodo + bits ulte karo
    ## Echo request words
    0800 + 0000 + 0001 + 0001 = 0802
    checksum = FFFF - 0802
    ! Checksum = F7FD
    ## Receiver check
    0800 + F7FD + 0001 + 0001
    = FFFF -> complement = 0000
    ! No error
    ## Carry demo: 8F3C + 7A5B
    = 10997 -> 0997 + 1 = 0998
    ! complement = F667

### Scene 4: IGMP = group mein join karne ki application local router ko
    ## Hex to decimal
    0x11 = 1x16 + 1 = 17
    0x16 = 1x16 + 6 = 22
    0x17 = 1x16 + 7 = 23
    ! query 17, report 22, leave 23
    ## Multicast groups
    all hosts = 224.0.0.1
    all routers = 224.0.0.2
    ~ Class D: 224 - 239

### Scene 5: 5 marks: Diagram + type table + ping/traceroute + checksum
    ## TTL idea
    TTL starts at e.g. 64
    each router: TTL - 1
    TTL = 0 -> drop + ICMP type 11
    ! Prevents infinite loops
    ## Example
    start TTL = 30, 12 routers
    arrives with 30 - 12 = 18
