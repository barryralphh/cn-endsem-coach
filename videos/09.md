# Routing: Distance Vector and Link State

## 10 Golden Points
1. Routing algorithm decides the best path for packets, a routing table stores the result
2. Distance vector uses Bellman-Ford: each router shares its table with neighbours only
3. Bellman-Ford equation: D(x,y) = minimum over neighbours v of cost(x,v) + D(v,y)
4. Link state uses Dijkstra: each router knows the full map and builds a shortest path tree
5. Count to infinity is the slow convergence problem of distance vector after a link failure
6. Solutions: split horizon, poison reverse, hold down timer, triggered update, limit infinity to 16
7. RIP is distance vector, hop count metric, maximum 15 hops, updates every 30 seconds, UDP port 520
8. OSPF is link state, uses cost metric, runs directly over IP protocol 89, supports areas
9. BGP is path vector, used between autonomous systems, runs over TCP port 179
10. Dijkstra steps: pick the unvisited node with the least distance, then relax its neighbours

## Worked calculations

### Scene 1: Distance vector = padosi se pucho | Link state = poora map
    ## Bellman-Ford rule
    D(x,y) = min [ c(x,v) + D(v,y) ]
    ## A starts knowing
    A to B = 2
    A to C = 5
    A to D = unknown
    ! Updates happen when neighbours share vectors

### Scene 2: Har update mein: padosi ka cost + link cost, minimum lo
    ## From B vector (A2, C1, D4)
    A->C = min(5, 2+1) = 3
    A->D = 2 + 4 = 6
    ## From C vector (C->D = 2)
    A->D via C = 3 + 2 = 5
    min(6, 5) = 5
    ! A: B=2, C=3, D=5

### Scene 3: Link toota -> dono ek doosre ko dhokha dete hain, cost badhta jaata hai
    ## Count to infinity (RIP)
    B->C fails
    B hears A: C = 2 -> B: C = 3
    A hears B: C = 3 -> A: C = 4
    B: 5, A: 6, B: 7 ...
    continues till 16 = infinity
    ! Fix: split horizon + poison reverse
    ~ RIP infinity = 16

### Scene 4: Dijkstra: sabse chhota unvisited chuno, uske padosi relax karo
    ## Relax edges
    pick B(2): C = min(5, 2+1) = 3
                 D = 2 + 4 = 6
    pick C(3): D = min(6, 3+2) = 5
    ! Final: B=2, C=3, D=5
    ! Path to D: A -> B -> C -> D
    ~ cost 2 + 1 + 2 = 5

### Scene 5: RIP = hop count | OSPF = cost, link state | BGP = path vector
    ## Quick numerical
    RIP: 12 hops -> reachable
    RIP: 16 hops -> unreachable
    ! max usable = 15 hops
    ## Update period
    RIP update every 30 s
    timeout 180 s (6 x 30)
    ~ garbage collection 120 s
