# Network Layer Mock Drill (Exam Style)

## 10 Golden Points
1. Exam pattern: about 65 percent numerical, so practise two numericals and one theory question
2. Five mark theory answer: definition, labelled diagram, key points, one example, 1.5 to 2.5 pages
3. Subnet drill: find block size = 256 minus mask octet, then find the block that holds the IP
4. Network address = IP AND mask, broadcast = network plus block size minus 1
5. Fragmentation drill: data per fragment = MTU minus 20, rounded down to a multiple of 8
6. Number of fragments = ceiling of total data divided by data per fragment
7. Offset = bytes already sent divided by 8, MF = 0 only for the last fragment
8. Hex to dotted decimal: each pair of hex digits is one octet
9. IPv6 compress: remove leading zeros and replace the longest zero run with a double colon
10. Always write the formula first, then substitute, then box the final answer with units

## Worked calculations

### Scene 1: Paper: 65% numerical. Formula -> values -> boxed answer
    ## Marks plan (40 marks)
    numericals ~ 65%

    theory ~ 35%
    = 0.35 x 40 = 14 marks

### Scene 2: Q1: 200.10.5.77/27 -> block size 32 -> 64 se 95
    ## Solve
    /27 -> mask 255.255.255.224
    block = 256 - 224 = 32
    64 <= 77 <= 95
    ! Network  : 200.10.5.64
    ! Broadcast: 200.10.5.95
    ! First host: .65, Last: .94
    Hosts = 2^5 - 2 = 30

### Scene 3: Q2: 5000 B, MTU 1000 -> 976 per fragment (8 ka multiple), 6 fragments
    ## Solve
    data = 5000 - 20 = 4980
    max = 1000 - 20 = 980
    980 / 8 = 122.5 -> use 122 x 8 = 976
    frags = 4980 / 976 = 5.1 -> 6
    last data = 4980 - 5x976 = 100
    offset step = 976 / 8 = 122
    ! last: offset 610, len 120, MF 0

### Scene 4: Q3: hex -> dotted, aur IPv6 compress (longest zero run)
    ## Hex to dotted: C0A80164
    C0 = 12x16 = 192
    A8 = 10x16 + 8 = 168
    01 = 1
    64 = 6x16 + 4 = 100
    ! 192.168.1.100 (Class C)
    ## IPv6 compress
    longest zero run -> ::
    other zeros stay as 0
    ! 2001::1:0:0:ABC
