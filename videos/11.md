# UDP (User Datagram Protocol)

## 10 Golden Points
1. UDP is connectionless and unreliable: no handshake, no ack, no retransmission
2. UDP header is only 8 bytes with four fields of 16 bits each
3. Fields: source port, destination port, length, checksum
4. Length field counts header plus data, so data length = length minus 8
5. Port numbers are 16 bits, from 0 to 65535. Well known ports are 0 to 1023
6. Client uses a random ephemeral port above 1023, server uses a well known port
7. Hex to decimal: multiply digits by 4096, 256, 16 and 1
8. Common UDP ports: DNS 53, DHCP 67 and 68, TFTP 69, SNMP 161
9. UDP checksum covers a pseudo header, the UDP header and the data
10. UDP is used for DNS, streaming, VoIP, gaming because it is fast with low overhead

## Worked calculations

### Scene 1: UDP = postcard: fast, halka, koi guarantee nahi
    ## Header size
    4 fields x 2 bytes = 8 bytes
    ! UDP header = 8 B
    ## Length field
    length = header + data
    data = length - 8
    ~ max length = 65,535

### Scene 2: Hex -> decimal: 4096, 256, 16, 1 se multiply karo
    ## Source port = CB84
    C = 12 x 4096 = 49152
    B = 11 x  256 =  2816
    8 =  8 x   16 =   128
    4 =  4 x    1 =     4
    49152 + 2816 + 128 + 4
    ! Source port = 52100

### Scene 3: Source bada (ephemeral), dest chhota (well known) = client -> server
    ## Destination port
    000D -> D = 13
    ! Dest port = 13 (daytime)
    ## Length = 001C
    1 x 16 + C(12) = 28
    ! Length = 28 bytes
    data = 28 - 8 = 20 bytes
    ## Direction
    52100 > 1023 -> ephemeral
    13 < 1024 -> well known
    ! CLIENT -> SERVER

### Scene 4: Practice: 0632 000D 001C E217 -> src 1586, dst 13, len 28
    ## Source = 0632
    0 x 4096 = 0
    6 x  256 = 1536
    3 x   16 =   48
    2 x    1 =    2
    ! Source port = 1586
    ## Rest
    dest = 000D = 13
    length = 001C = 28
    checksum = E217 (hex)

### Scene 5: Checksum = sum + carry wapas + complement
    ## Checksum of AAAA, 5555, 0F0F
    AAAA + 5555 = FFFF
    FFFF + 0F0F = 1 0F0E
    wrap carry: 0F0E + 1 = 0F0F
    complement = FFFF - 0F0F
    ! Checksum = F0F0
    ## Verify
    FFFF + 0F0F + F0F0 = 1FFFE
    1FFFE -> FFFE + 1 = FFFF
    ! all ones -> OK
