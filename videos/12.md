# TCP: Header, Flags, Handshake, Sequence Numbers

## 10 Golden Points
1. TCP is connection oriented, reliable, full duplex and byte stream based
2. TCP header is minimum 20 bytes and maximum 60 bytes, with 6 flags
3. SYN opens a connection, ACK acknowledges, FIN closes, RST resets, PSH pushes data, URG marks urgent data
4. Three way handshake: SYN, then SYN plus ACK, then ACK
5. SYN and FIN each consume one sequence number, a pure ACK consumes none
6. Next sequence number = current sequence number + data bytes, plus 1 for SYN or FIN
7. Acknowledgement number is the next byte the receiver expects
8. Connection close uses four steps: FIN, ACK, FIN, ACK, and TIME WAIT lasts 2 times MSL
9. Sequence number field is 32 bits so it wraps after 2 to the power 32 bytes
10. Wrap time = (2 to the power 32 minus starting number) divided by data rate

## Worked calculations

### Scene 1: TCP = phone call: pehle handshake, phir baat
    ## Header length
    HLEN = 5 -> 5 x 4 = 20 B (min)
    HLEN = 15 -> 15 x 4 = 60 B (max)
    ! Options up to 40 bytes
    ## Flags (6)
    URG ACK PSH RST SYN FIN

### Scene 2: Flags: SYN open | ACK confirm | FIN close | RST reset
    ## Remember
    SYN  -> Start
    ACK  -> Agree
    FIN  -> Finish
    RST  -> Refuse / reset
    ! Any 4 are enough for 4 marks
    ## Flag bits
    6 flags = 6 bits
    ~ order: URG ACK PSH RST SYN FIN

### Scene 3: SYN aur FIN = 1 sequence number khaate hain. ACK = 0
    ## Numbers
    client ISN x = 8000
    server ISN y = 15000
    1) SYN: seq=8000
    2) SYN+ACK: seq=15000, ack=8000+1
    ! ack = 8001
    3) ACK: seq=8001, ack=15000+1
    ! ack = 15001

### Scene 4: Data seq = ISN + 1. FIN seq = data seq + bytes
    ## Compute
    SYN seq = ISN = 2171
    next = 2171 + 1 = 2172
    Data seq = 2172
    next = 2172 + 1500 = 3672
    ! FIN seq = 3672
    ## Same with 1000 bytes
    data seq = 2172
    FIN seq = 2172 + 1000 = 3172
    ~ bytes 2172 .. 3171

### Scene 5: Wrap time = (2^32 - start) / data rate
    ## Compute
    2^32 = 4,294,967,296
    remaining = 4,294,967,296 - 7,000
              = 4,294,960,296 bytes
    rate = 1 MB/s = 1,000,000 B/s
    time = 4,294,960,296 / 1,000,000
    ! = 4294.96 s  (about 71.6 min)
    ~ if 1 MB = 2^20 B: 4096 s

### Scene 6: Close: FIN, ACK, FIN, ACK. Client TIME_WAIT = 2 x MSL
    ## States
    Server: LISTEN -> SYN_RCVD -> ESTABLISHED
    Client: SYN_SENT -> ESTABLISHED
    Closing: FIN_WAIT_1 -> FIN_WAIT_2
    CLOSE_WAIT -> LAST_ACK -> CLOSED
    ! TIME_WAIT = 2 x MSL
    ~ MSL = 30 s to 2 min
