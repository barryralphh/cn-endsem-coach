# TCP Timers, RTT and Options

## 10 Golden Points
1. TCP uses four main timers: retransmission, persistence, keepalive and time wait
2. Retransmission timeout RTO should be a little more than the round trip time
3. Smoothed RTT: SRTT = 0.875 x SRTT + 0.125 x new RTT
4. RTT variation: RTTVAR = 0.75 x RTTVAR + 0.25 x absolute of (SRTT minus new RTT)
5. RTO = SRTT + 4 x RTTVAR. For the first sample SRTT = RTT, RTTVAR = RTT divided by 2
6. Karn algorithm: do not use RTT of retransmitted segments, and double the RTO on every timeout
7. Persistence timer sends probes when the receiver window is zero
8. Keepalive timer checks if the other side is still alive, usually after 2 hours
9. Time wait timer is 2 times MSL after active close
10. Options: MSS, window scale, timestamp, SACK, and NOP for padding

## Worked calculations

### Scene 1: Timer = kitni der wait karein? Na jaldi, na der
    ## Idea
    RTO slightly above RTT
    too short -> useless resends
    too long -> slow recovery
    ! RTO is adaptive
    ~ measured from ACK times

### Scene 2: RTO = SRTT + 4 x RTTVAR. Pehle RTTVAR update, phir SRTT
    ## Sample 1: RTT = 200 ms
    SRTT = 200
    RTTVAR = 200 / 2 = 100
    RTO = 200 + 4 x 100 = 600
    ## Sample 2: RTT = 300 ms
    RTTVAR = 0.75x100 + 0.25x|200-300|
           = 75 + 25 = 100
    SRTT = 0.875x200 + 0.125x300
         = 175 + 37.5 = 212.5
    ! RTO = 212.5 + 400 = 612.5 ms

### Scene 3: Sample 3: RTT = 100 ms -> RTO = 610.9 ms
    ## Sample 3: RTT = 100
    RTTVAR = 0.75x100 + 0.25x|212.5-100|
           = 75 + 28.125 = 103.125
    SRTT = 0.875x212.5 + 0.125x100
         = 185.94 + 12.5 = 198.44
    ! RTO = 198.44 + 4x103.125
    !     = 610.94 ms

### Scene 4: Old style: RTT = a x old + (1 - a) x sample; RTO = 2 x RTT
    ## Q: old 30 ms, sample 26, a = 0.9
    RTT = 0.9x30 + 0.1x26
        = 27 + 2.6
    ! RTT = 29.6 ms
    RTO = 2 x 29.6
    ! RTO = 59.2 ms
    ## Backoff
    timeout #1: RTO = 59.2
    timeout #2: 118.4, #3: 236.8

### Scene 5: Throughput ~ (MSS / RTT) x 1.22 / sqrt(p)
    ## Q: MSS 1460 B, RTT 100 ms, p = 1 %
    MSS = 1460 x 8 = 11,680 bits
    MSS / RTT = 116,800 bps
    1.22 / sqrt(0.01) = 12.2
    thr = 116,800 x 12.2
    ! = 1,424,960 bps = 1.42 Mbps
