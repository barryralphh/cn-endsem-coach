# DNS and DHCP

## 10 Golden Points
1. DNS maps a domain name to an IP address, it is the phonebook of the internet
2. DNS is a distributed hierarchical database: root, top level domain, authoritative servers
3. DNS mostly uses UDP port 53, and TCP port 53 for zone transfers
4. Recursive query: the server does all the work. Iterative query: the server gives the next server to ask
5. Record types: A for IPv4, AAAA for IPv6, NS name server, CNAME alias, MX mail server, PTR reverse lookup
6. DNS caching with TTL reduces lookup time and load
7. Page fetch time with DNS = sum of all DNS RTTs + 2 x RTT to the web server
8. DHCP automatically gives IP address, mask, default gateway and DNS server
9. DHCP steps DORA: Discover, Offer, Request, Acknowledge. Ports: server 67, client 68
10. Lease renewal: T1 is 50 percent of lease time and T2 is 87.5 percent

## Worked calculations

### Scene 1: DNS = phonebook: naam -> IP address
    ## Resource records
    A     name -> IPv4
    AAAA  name -> IPv6
    NS    name server
    CNAME alias
    MX    mail server
    PTR   IP -> name
    ! 6 records to remember

### Scene 2: Recursive = poora kaam server kare | Iterative = agla server bata do
    ## Queries
    Host to local DNS: recursive
    Local DNS to others: iterative
    ## Cache
    entry has a TTL (seconds)
    TTL = 0 -> not cached
    ! Cache = fewer lookups
    ~ negative caching also exists

### Scene 3: Time = RTT1 + ... + RTTn + 2 x RTT0
    ## Q: RTTs 3, 10, 30; web RTT0 = 20
    DNS = 3 + 10 + 30 = 43 ms
    HTTP = 2 x 20 = 40 ms
    ! Total = 43 + 40 = 83 ms
    ## If DNS is cached
    time = 2 x 20
    ! = 40 ms

### Scene 4: DHCP = DORA: Discover, Offer, Request, Ack
    ## Discover packet
    src IP = 0.0.0.0
    dst IP = 255.255.255.255
    ports: 68 -> 67
    ! client does not have an IP yet
    ## Gets
    IP + mask + gateway + DNS
    ~ lease time included

### Scene 5: T1 = 50% of lease, T2 = 87.5% of lease
    ## Q: lease = 8 hours
    T1 = 0.5 x 8 = 4 hours
    T2 = 0.875 x 8 = 7 hours
    ! T1 = 4 h, T2 = 7 h
    ## Lease = 24 hours
    T1 = 12 h
    T2 = 0.875 x 24 = 21 h
