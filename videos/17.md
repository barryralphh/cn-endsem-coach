# HTTP, WWW, Email (SMTP) and FTP

## 10 Golden Points
1. WWW is a distributed system of web pages, HTTP is the protocol used to fetch them, default port 80
2. URL has protocol, host name, port and path, for example http colon slash slash host slash path
3. HTTP is stateless and uses TCP. Cookies add state to it
4. HTTP methods: GET, POST, PUT, DELETE, HEAD
5. Status codes: 200 OK, 301 moved, 304 not modified, 400 bad request, 404 not found, 500 server error
6. Web documents have three types: static, dynamic and active
7. Non persistent HTTP needs 2 RTT per object, persistent HTTP needs 1 RTT per object after the first connection
8. SMTP is a push protocol on TCP port 25, POP3 port 110 and IMAP port 143 are pull protocols
9. SMTP commands: HELO, MAIL FROM, RCPT TO, DATA, QUIT. MIME allows non text attachments
10. FTP uses two connections: control on port 21 and data on port 20. Telnet uses port 23

## Worked calculations

### Scene 1: HTTP = restaurant: request -> response. Stateless!
    ## Methods
    GET   fetch a page
    POST  send data
    PUT   upload
    DELETE remove
    HEAD  headers only
    ## Status codes
    200 OK | 301 Moved | 304 Not mod.
    400 Bad req | 404 Not found
    ! 500 Server error

### Scene 2: Static (fixed) | Dynamic (server banata hai) | Active (browser chalata hai)
    ## Easy memory
    Static  = photo (never changes)
    Dynamic = live score (server)
    Active  = game (runs in browser)
    ! 3 types: static, dynamic, active

### Scene 3: Non-persistent = 2 RTT per object | Persistent = 1 RTT per object
    ## Non-persistent serial
    11 objects x 2 RTT = 22 RTT
    22 x 100 ms = 2.2 s
    ## Persistent, no pipeline
    1 handshake + 11 x 1 = 12 RTT
    12 x 100 = 1.2 s
    ## Pipelined
    1 + 1 + 1 = 3 RTT = 0.3 s
    ! Persistent + pipeline is fastest

### Scene 4: SMTP = push (25) | POP3 / IMAP = pull (110 / 143)
    ## SMTP dialogue
    S: 220 ready
    C: HELO client.com
    S: 250 OK
    C: MAIL FROM:<a@x.com>
    C: RCPT TO:<b@y.com>
    C: DATA  -> S: 354 go ahead
    C: ...message...  .
    C: QUIT -> S: 221 bye
    ! ports: SMTP 25, POP3 110, IMAP 143

### Scene 5: FTP: control 21 + data 20 | Telnet: port 23 (insecure)
    ## Remember
    FTP -> 2 connections
    control: persistent
    data: per file
    ! Telnet sends password in clear text
    ## Download time
    file = 10 MB = 80 Mbit
    link = 8 Mbps
    time = 80 / 8 = 10 s
