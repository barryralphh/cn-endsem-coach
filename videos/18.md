# Encryption and RSA

## 10 Golden Points
1. Encryption converts plaintext into ciphertext using an algorithm and a key
2. Symmetric key: same key for encryption and decryption, fast, example DES and AES
3. Asymmetric key: public key encrypts and private key decrypts, slower, example RSA
4. For n users symmetric needs n times n minus 1 divided by 2 keys, asymmetric needs 2n keys
5. DES has 64 bit block, 56 bit key and 16 rounds. AES has 128 bit block and key of 128, 192 or 256 bits
6. Caesar cipher shifts each letter by k, HELLO with k equals 3 becomes KHOOR
7. RSA steps: pick primes p and q, n = p x q, phi = (p minus 1)(q minus 1), pick e, find d with e x d mod phi = 1
8. RSA encrypt C = M to the power e mod n, decrypt M = C to the power d mod n
9. Public key is (e, n), private key is (d, n)
10. Diffie Hellman agrees a shared secret key: A = g to the a mod p, B = g to the b mod p, key = B to the a mod p

## Worked calculations

### Scene 1: Symmetric = ek chaabi | Asymmetric = padlock (public) + chaabi (private)
    ## Number of keys, n = 10
    symmetric: n(n-1)/2
               = 10 x 9 / 2 = 45
    asymmetric: 2n = 20
    ! 45 keys vs 20 keys
    ## Caesar, k = 3
    H E L L O
    K H O O R
    ! HELLO -> KHOOR

### Scene 2: RSA: p, q -> n -> phi -> e -> d
    ## p = 3, q = 11
    n = 3 x 11 = 33
    phi = 2 x 10 = 20
    e = 7  (gcd(7,20) = 1)
    d: 7 x d mod 20 = 1
    7 x 3 = 21 = 1 mod 20
    ! Public (7, 33), Private (3, 33)

### Scene 3: Encrypt: M^e mod n | Decrypt: C^d mod n
    ## Encrypt M = 2
    C = 2^7 mod 33
      = 128 mod 33
      = 128 - 99
    ! C = 29
    ## Decrypt
    M = 29^3 mod 33
    29 = -4 mod 33
    (-4)^3 = -64
    -64 + 99 = 35 -> 35 - 33 = 2
    ! M = 2  (original recovered)

### Scene 4: p=5, q=7: n=35, phi=24, e=5, d=5, M=12 -> C=17
    ## Encrypt M = 12
    12^2 = 144 mod 35 = 4
    12^4 = 4^2 = 16
    12^5 = 16 x 12 = 192
    192 mod 35 = 192 - 175
    ! C = 17
    ## Decrypt
    17^2 = 289 mod 35 = 9
    17^4 = 81 mod 35 = 11
    17^5 = 11 x 17 = 187 -> 12
    ! M = 12

### Scene 5: DH: A = g^a mod p, B = g^b mod p, key = B^a mod p = A^b mod p
    ## Compute
    A = 5^6 mod 23 = 8
    B = 5^15 mod 23 = 19
    ## Shared key
    Alice: B^a = 19^6 mod 23
    19 = -4 -> (-4)^6 = 4096
    4096 mod 23 = 2
    Bob: A^b = 8^15 mod 23 = 2
    ! Shared secret key = 2
