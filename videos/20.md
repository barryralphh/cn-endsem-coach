# Firewall and Intrusion Detection System

## 10 Golden Points
1. A firewall sits between a trusted network and the internet and filters traffic using rules
2. Packet filter firewall checks source IP, destination IP, port and protocol, it is stateless and fast
3. Stateful inspection firewall remembers connections in a state table
4. Application proxy firewall works at the application layer and inspects the content
5. Rules are checked from top to bottom, first match wins, last rule is usually deny all
6. DMZ is a separate zone for public servers like web and mail, placed between two firewalls
7. Firewall cannot stop attacks from inside, viruses in allowed traffic, or bypass through a modem
8. IDS monitors traffic and raises an alarm, it does not block. IPS can also block the attack
9. Signature based IDS detects known attacks, anomaly based IDS detects unusual behaviour and can find new attacks
10. HIDS runs on a host, NIDS monitors a network segment. Detection rate = detected divided by total attacks

## Worked calculations

### Scene 1: Firewall = gate guard | IDS = CCTV + alarm | IPS = guard + alarm
    ## One line each
    Firewall: filters by rules
    IDS: detects and alarms
    IPS: detects and blocks
    ! Layered security = all three

### Scene 2: Packet filter (header) < Stateful (connections) < Proxy (content)
    ## Rule order
    top to bottom
    first match wins
    last rule: DENY ALL
    ! Default deny is safest
    ## Layers
    packet filter -> network/transport
    proxy -> application

### Scene 3: Top se neeche check karo, jo pehla match mile wahi final
    ## A: TCP 8.8.8.8 -> 192.168.1.10:80
    matches rule 1
    ! ALLOW
    ## B: TCP 8.8.8.8 -> 192.168.1.10:23
    rule 1 no (port 23), rule 2 no
    rule 3 matches
    ! DENY
    ## C: UDP LAN host -> 1.1.1.1:53
    rule 2 matches
    ! ALLOW

### Scene 4: DMZ = public servers ke liye alag zone. Firewall ki limits yaad rakho
    ## Limits of firewall
    1. Cannot stop insider attacks
    2. Cannot catch virus in allowed traffic
    3. Cannot stop bypass (modem, USB)
    4. Needs correct rules
    ! Firewall alone is not enough

### Scene 5: Signature = known | Anomaly = unusual | HIDS = host | NIDS = network
    ## Detection rate
    100 attacks, IDS detects 90
    rate = 90 / 100
    ! Detection rate = 90 %
    ## False alarm rate
    1000 normal events, 20 flagged
    FPR = 20 / 1000
    ! = 2 %
    ~ missed attacks = false negatives
